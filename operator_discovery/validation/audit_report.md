## One-line verdict

**Fix-then-ship — and the validation GATES need fundamental rework.** The binding-site _predictions_ are real (operator recovered; genome-wide specificity 0.2%; negative controls clean), but **G1/G2/G4 are circular/leaky and the FDR is not a true genome-wide BH** — so the headline "4/5 pre-registered gates pass = validated" is **not defensible as written**. The science survives as "the operator PWM is specific genome-wide and clade-conserved"; the independence/enrichment claims do not.

### DISAGREEMENT — the most informative output

**FIMO threshold mode (Claude-internal + cross-family).**

- Claude **D2** (`validate.py:124-128 + run_fimo.py:64-65`) asserted FIMO is invoked with `--qv-thresh --thresh 0.05`, concluding the q-gate is "vacuous because FIMO already q-thresholds."
- Codex **pass 1** (`main.py:240`) and Claude **D5** (`main.py:239-246`) assert FIMO is invoked with `use_qvalue=False` → **p-value** threshold, q-values anti-conservative.

**Resolution — Codex + Claude-D5 are correct; Claude-D2 is wrong.** `main.py` calls `run_fimo(..., use_qvalue=False, qv_thresh=scan_pthresh=1e-3)`; in `run_fimo.py` that takes the `else` branch → `--thresh 1e-3` (p-value), **not** `--qv-thresh`. So the FDR is not enforced upstream by FIMO at q<0.05; it is a p<1e-3 report whose q-values validate then filters. This is the single most consequential converged finding (C3): both families, via different routes, conclude the **q-value gate does not deliver a genuine genome-wide BH FDR** — the disagreement was only over the mechanism, and the code settles it.

**Agreement on a non-finding:** both families confirm **no shell-injection** — all `subprocess.run` calls use list args with `shell=False`, tool paths resolved via `shutil.which`/existence checks (Claude D6 explicit; Codex raised no injection issue).

## Six-dimension summary

1. **Research rigor / claim validity — FAIL as stated.** G1/G2/G4 circular/leaky (C1,C2,C4); the only clean, non-circular evidence is G3 specificity + clean negative controls + honestly-reported G5 7/8.
2. **Gate / eval honesty — FAIL.** A motif that memorized only its two training operators passes G1–G4 (C1,C2,C5,C10); nulls don't match prereg (C8); n=6 positives, no CI.
3. **Code correctness — multiple real bugs.** C5 (per-seq/per-site), S1 (hypergeom args), S2 (minus-strand fetch), S4 (window fallback), S10 (sort inversion), S11 (tie ranks).
4. **Reproducibility — gaps.** No provenance (S6), lower-bound deps (S9), live un-versioned NCBI ortholog fetch driving G1/G2/G5, non-idempotent extract (C11), `all_core_pass` excludes G1/G5 (Codex, both passes).
5. **Data contract — partial.** FIMO TSV parser silently degrades to score-only if q-column absent (C3-adjacent); inputs reused without schema/dup/coordinate validation; circular-genome not wrapped (S8); ortholog identity by name only (S7).
6. **Security / IO — clean except minor.** No injection, no secrets; hardcoded personal email (C12), unsanitized organism string into FASTA, unclosed file handle in `build_background.py:59`.
